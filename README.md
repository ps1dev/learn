# learn

Programming the PlayStation with modern C++ and [psyqo](https://github.com/pcsx-redux/nugget/tree/main/psyqo), one piece of the machine per chapter.

Each chapter explains what the hardware does, then builds a small runnable example on top of psyqo. Hardware facts cite [psx-spx](https://psx-spx.consoledev.net/dev/) or a measurement on real hardware. For the same ground without an SDK, read [ps1-bare-metal](https://github.com/spicyjpeg/ps1-bare-metal).

Work in progress: the chapter outline is up for comments first.
